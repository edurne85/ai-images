# Duplicate Files Finder on command line:

`cd C:\Program Files (x86)\Duplicate Files Finder`

_May depend on local `.exe` and `.dll` files_

`dupf -q D:\OneDrive\Escritorio\18+\GenAI\sources -h -z`

- `-q` Quiet: don't display progress info
- `-h` Include hidden files
- `-z` Include zero-size files
